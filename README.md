# Student Grade Predictor

## Description
Student Grade Predictor is a Machine Learning mini project that predicts a student's final grade based on academic performance features. The project uses a Decision Tree Classifier to classify students into different grade categories.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning (Decision Tree Classifier)

## Dataset
The dataset contains student academic information used to train the machine learning model and predict the final grade of students.

## Methodology
The project follows these steps:

1. Load the student dataset
2. Preprocess the data and convert grades into numerical values
3. Split the dataset into training and testing data
4. Train a Decision Tree Classifier model
5. Evaluate the model using accuracy score
6. Predict the grade of a new student
