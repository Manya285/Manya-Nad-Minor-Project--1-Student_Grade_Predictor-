# 🎓 Student Grade Predictor

## 📌 Description

Student Grade Predictor is a Machine Learning-based application that predicts a student's grade category based on academic performance features. The project uses a Decision Tree Classifier to analyze student data and classify students into different grade levels.

The aim of this project is to help understand how machine learning algorithms can be used for prediction and decision-making in the education domain.

## ✨ Features

- Predict student grades using Machine Learning
- Uses Decision Tree Classification algorithm
- Takes academic performance inputs
- Provides predicted grade category
- Simple and user-friendly interface
- Data preprocessing and model training

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook / Python Environment

### 1. Install required libraries

```

```

### 2. Run the application

```
python src/grade_predictor.py
```

## 📊 Project Workflow

1. Collect student academic data
2. Preprocess the dataset
3. Train the Decision Tree Classifier model
4. Test the model
5. Predict student grade category

## 🎯 Objective

The objective of this project is to apply machine learning techniques for predicting student performance and demonstrate the practical use of classification algorithms.
